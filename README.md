# 注意
## ファイル編集時について
1. 編集は自動的CommitHistoryに記録されます。過去の履歴を見る場合は[こちら](https://github.com/CheeseHackerXYZ/nazotoki/commits/)から参照してください。
2. 確認した際にわかりやすいように、**コメントアウトに変更点を書き込んで**ください。
3. 大きな変更は、**CHANGELOG.mdに記載**すること。
4. 編集する際は信頼できるコードであることを確認してください。不明なコードの場合、**PullRequstを利用**することも可能です。

## 新規プロジェクトについて
1. 以下の基準によって、どのディレクトリにアップロードするかを確認してください。
- スニペット(コード素材): ディレクトリ「`Snippets`」を使用してください
- AI生成が80%以上: ディレクトリ「`AI_generate`」を使用してください
- AI生成が50%程度: ディレクトリ「`Half_generate`」を使用してください
- 完全に人間の手で手直しされている: ディレクトリ「`Original`」を使用してください
2. スニペットの場合、使用方法を詳しく記載してください。また可能なかぎりサンプルもアップロードしてください。
3. トップページのファイルは「`index.html`」に設定してください。
4. 自動デプロイされない場合があります。その場合はオーナーに連絡してください。
5. 25MB以上のファイルはアップロードできません。

- 招待制にして荒らしは防止する

## deploy
- Cloudflareを主に使用
