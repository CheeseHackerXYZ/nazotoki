Web完結型ARG 企画書
1. 概要
本企画は、ネットオークションに出品された「怪しいブツ（呪物・からくり箱）」の真相を追い、怪異の拡散を阻止する体験型Webコンテンツ（ARG: 拡張現実ゲーム）である。
作中サイト内の文章・画像・専用ギミックツールを操作することで直感的に謎を解き明かす没入感を重視した設計とする。
2. 世界観・基本設定
* 怪しいブツの正体: 明治時代に封印された憑依型の怪異が宿る「からくり箱」。誤った方法で開けようとすると怪異が拡散し、所有者の精神を破綻させる。
* 解錠（封印）の理由: 怪異を無力化して safe に回収するには、からくり箱の「正しい解錠手順」を特定し、専門機関に引き渡す必要がある。
* 主要人物/プレイヤーの立場:
    * 出品者 (@seller_123): 怪異に耐えかね、オークションに出品して手放そうとした人物。
    * プレイヤー: 依頼者からのタレコミを受け、事件の調査・解決を試みる捜査者。
3. システム・設計原則
1. F12（ソースコード解析）の完全禁止: 隠しデータやヒントはすべて画面上の視覚情報・テキスト・作中Webツールで表現する。
2. 作中ツールの導入: 画面上に「明るさ・コントラスト調整」「荷物追跡システム」などのギミックを配置し、世界観の演出と謎解きを一体化させる。
3. ゲームオーバーと復帰: 時間制限（Phase 9）による失敗時はBad Endとなるが、演出後すぐに「直前からやり直す」ボタンを表示し、ストレスなく再挑戦できる構造とする。
4. 全10 Phase 動線仕様
Phase 1: 噂のタレコミと出品ページ
* 導入: 依頼者から「ヤミオクでヤバい出品がある。もうすぐオークションが終了してしまうから調べてくれ」とURLが届く。
* 画面: ネットオークション「ヤミオク」の出品ページ「【訳あり】古い木箱」。
* 行動/突破: 商品説明欄に記載されている出品者ID（@seller_123）を確認し、アカウントページへアクセスする。
Phase 2: 出品者アカウントと自主退会メッセージ
* 展開: @seller_id のページを開くと「退会済み」の表示。
* 画面: 退会画面の「退会理由・ユーザーからのメッセージ」欄。
* 行動/突破: メッセージ内に「今後の報告や日記は個人のWebサイト（URL）で…」と残された文面から、出品者の個人ブログURLを特定する。
Phase 3: 個人ブログと発送伝票の発見
* 展開: @seller_id が木箱を入手してから精神を病んでいく日常ブログ。
* 画面: 最後の記事「本日発送完了。これでやっとあの箱から解放される」と、梱包された木箱の写真。
* 行動/突破: 写真の端（机の上）に写り込んだ「1回目の発送時の伝票控え（メモ）」を拡大・観察し、12桁の配送番号を発見する。
Phase 4: 配送追跡と保管場所の特定
* 展開: 架空の運送会社「BlackDelivery」の荷物追跡ページ。
* 画面: 12桁の配送番号を入力した後のステータス画面。
* 行動/突破: 「受取拒否のため『中央区第3物流センター・地下貴重品庫』にて一時保管中」という表示と、案内文に記載された「保管庫管理システム」へのアクセスリンクを発見する。
Phase 5: 保管庫のアクセスログ・監視スナップショット
* 展開: 保管庫管理システムの公開監視・ログビュー。
* 画面: 深夜帯の監視カメラ静止画（スライドショー）
* 行動/突破: 過去の画像を見るからx線スキャン画像を取得
Phase 7: 画像解析ツールによる構造図の浮き彫り
* 展開: 取得した暗い画像。
* 画面/ギミック: サイト上に配置された「明度・コントラスト調整スライダー」。
* 行動/突破: スライダーを操作して画像を明瞭に補正し、木箱の側面に刻まれた「からくりの構造図」を出現させる。
Phase 8: 匿名掲示板の情報精査
* 展開: ダークウェブ風の掲示板から、この木箱の元所有者たちの書き込みを調べる。
* 画面: 無数のデマや推測が飛び交うスレッド群。
* 行動/突破: Phase 7で得た構造図と照らし合わせ、矛盾しない唯一の本物情報を見極め、安全な「正しい解錠手順（パズル手順）」を特定する。
Phase 9: 自動再出品と制限時間付き転送フォーム
* 展開: ヤミオクの自動再出品システムにより、2回目のオークションが終了。「新たな落札者へ自動出荷開始」のアラートとカウントダウンタイマー（例: 5分）が作動。
* 画面: 配送先変更および取扱指示フォーム。
* 行動/突破: 「回収先住所」とPhase 8で特定した「正しい解錠手順」を選択・入力して送信する。（失敗時はBad End演出後、直前からリトライ可能）
Phase 10: エピローグとマルチエンディング
* Normal End: 回収には成功したが、解錠手順の指定を間違えた（または省略した）ため、回収スタッフが被害に遭う。ヤミオクには再び別の怪しい出品が掲載される。
* True End: 正しい解錠手順を指定して転送に成功。木箱は安全に解錠・無力化され、後日 @seller_id のブログが更新されて意識を取り戻した旨が報告され、事件解決となる。
