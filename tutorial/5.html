CSS Animation 完全攻略ガイド

「transition」から「@keyframes」「3D変形」「GPU最適化」まで動きの仕組みを完全解説

0. なぜCSSでアニメーションを作るのか？

WebサイトやWebゲームで「ボタンを滑らかに凹ませる」「メニューをスッと出す」「キャラクターを揺らす」といった動きを作る時、JavaScriptを使わなくてもCSSだけで超軽量・滑らかに動かすことができます。

  • JavaScriptより圧倒的に軽くて速い： ブラウザのGPU（画像処理チップ）に処理を任せられるため、画面がカクつきにくい。
  • コードがシンプル： 数行のCSSを書くだけで実装できる。

CSSのアニメーションには大きく分けて「transition（トランジション）」と「animation（アニメーション / keyframes）」の2種類があります。

1. transition（変化を滑らかにする）

transition は、ホバー（:hover）やクラスの追加など、「状態が変わったとき」にAからBへじわっと変化させる仕組みです。

LIVE DEMO: Hover me!

書き方と4つのプロパティ

/* 個別指定の書き方 */
.button {
  background-color: #6366f1;
  transition-property: transform, background-color; /* 変化させるプロパティ */
  transition-duration: 0.3s;                        /* 変化にかかる時間 */
  transition-timing-function: ease;                /* 加速・減速のグラデーション */
  transition-delay: 0s;                            /* 開始までの待ち時間 */
}

/* 一括指定（Shorthand）の書き方（よく使う！） */
.button {
  /* transition: [プロパティ] [時間] [タイミング機能] [遅延]; */
  transition: all 0.3s ease;
}

.button:hover {
  background-color: #a855f7;
  transform: translateY(-5px);
}

2. @keyframes と animation（本格アニメーション）

ユーザーの操作（ホバー等）がなくても、「ずっとループして動かしたい」「複数のステップで複雑に動かしたい」時は @keyframes と animation プロパティを使います。

ステップ1：@keyframes でコマ割りを作る

アニメーションの「シナリオ（コマ割り）」を定義します。0%（開始）から 100%（終了）までの状態を指定します。

/* 「float」という名前のアニメーションシナリオを作成 */
@keyframes float {
  0% {
    transform: translateY(0px); /* 最初は元の位置 */
  }
  50% {
    transform: translateY(-20px); /* 半分で20px上に移動 */
  }
  100% {
    transform: translateY(0px); /* 最後は元の位置に戻る */
  }
}

ステップ2：要素に animation プロパティを割り当てる

LIVE DEMO: Floating Object
Float

animation の 8 大プロパティ

animation-name

適用する @keyframes の名前を指定。（例：float）

animation-duration

1回のアニメーションにかかる時間。（例：2s, 500ms）

animation-timing-function

動きの緩急。（ease, linear, ease-in-out など）

animation-iteration-count

再生回数。数字で指定、または無限ループなら infinite。

animation-direction

再生方向。normal（通常）、reverse（逆再生）、alternate（行って戻る）。

animation-fill-mode

再生前後の状態保持。forwards にするとアニメーション終了時の状態を維持する。

一括指定（Shorthand）：

.box {
  /* 名前 時間 タイミング 繰り返し 方向 */
  animation: float 3s ease-in-out infinite alternate;
}

3. アニメーションの最強の相棒：transform（変形）

CSSアニメーションで最もよく動かすのが transform プロパティです。要素の「位置」「大きさ」「回転」「傾き」を自由自在に変形できます。

関数 効果 コード例
translate(x, y) 位置を移動する transform: translateX(50px);
scale(x, y) 拡大・縮小する（1.0が標準） transform: scale(1.2);
rotate(deg) 回転させる（degは度数） transform: rotate(45deg);
skew(x, y) 斜めに傾ける transform: skewX(10deg);

3D変形（立体アニメーション）

perspective（遠近感）と rotateY を組み合わせると、3Dカードフリップが作れます。

LIVE DEMO: 3D Flip (Hover)
FRONT
BACK
/* 3Dカードフリップの骨組み */
.card-container {
  perspective: 1000px; /* 奥行き（遠近感）を設定 */
}

.card-inner {
  transition: transform 0.6s;
  transform-style: preserve-3d; /* 3D空間を維持 */
}

.card-container:hover .card-inner {
  transform: rotateY(180deg); /* Y軸中心に半回転 */
}

.card-front, .card-back {
  backface-visibility: hidden; /* 裏返った時は背面を非表示にする */
}

4. 動きの質感を変える「Timing Function」

同じ距離を移動するアニメーションでも、加減速（イージング）によって印象が全く変わります。

代表的なイージング

  • linear：等速（一定のスピード）。回転スピナーなどに使う。
  • ease（初期値）：ゆっくり始まって一気に加速し、最後は減速。自然な動き。
  • ease-in：じわっと動き出し、最後まで加速。
  • ease-out：勢いよく動き出し、最後はゆっくり止まる（UIパーツにお勧め！）。
  • ease-in-out：ゆっくり動き出し、ゆっくり止まる。

カクカク動かす `steps()`

ドット絵キャラの歩行アニメーションや、タイプライター風テキストアニメーションには steps(コマ数) を使います。

LIVE DEMO: steps(4) Animation
👾
/* コマ送り風アニメーション */
.pixel-art {
  animation: walk 1s steps(4) infinite;
}

5. すぐ使える！実践アニメーションパーツ集

① くるくる回るローディングスピナー

DEMO: Loading Spinner 
.spinner {
  width: 50px;
  height: 50px;
  border: 5px solid rgba(255, 255, 255, 0.1);
  border-top-color: #ec4899; /* 上の枠線だけ色をつける */
  border-radius: 50%;         /* 円にする */
  animation: spin 1s linear infinite; /* ずっと等速で回す */
}

@keyframes spin {
  0% { transform: rotate(0deg); }
  100% { transform: rotate(360deg); }
}

② 脈動する波紋（パルス）エフェクト

DEMO: Pulse Effect
NEW
.pulse-badge {
  animation: pulse-anim 2s infinite;
}

@keyframes pulse-anim {
  0% {
    transform: scale(0.95);
    box-shadow: 0 0 0 0 rgba(6, 182, 212, 0.7);
  }
  70% {
    transform: scale(1);
    box-shadow: 0 0 0 20px rgba(6, 182, 212, 0); /* 影を大きく外側に広げて透明にする */
  }
  100% {
    transform: scale(0.95);
    box-shadow: 0 0 0 0 rgba(6, 182, 212, 0);
  }
}

③ エラー時にブルブル震える（シェイク）

6. 超重要！ヌルヌル動かすための最適化ルール

アニメーションを作った時に「なんか画面がカクつく…」となる最大の原因は、ブラウザに負荷がかかるプロパティを動かしているからです。

❌ 動かすと重いプロパティ（リフローが発生）

top, left, width, height, margin, padding

これらを動かすと、ブラウザはアニメーションの毎フレームごとに「画面全体のレイアウト計算」をやり直すため、激重になります。

⭕ 動かしても激軽なプロパティ（GPU加速）

transform (位置・大きさ・回転) と opacity (透明度)

この2つだけは、ブラウザが「GPU（グラフィックカード）」に直接計算を放り投げることができるため、どれだけ動かしてもぬるぬる（60fps）で動きます！

💡 鉄則まとめ：
位置を変えるときは left: 10px; ではなく transform: translateX(10px); を使う！
