1. 基本文法 & データ型

1.1 変数宣言（const, let）とスコープの仕組み

JavaScriptにおいて変数を宣言するキーワードは主に const と let です。（※ var は再宣言可能かつスコープの挙動が複雑なため現在では非推奨です。）

  • const (定数): 再代入が不可能な変数を宣言します。基本的にはすべての変数宣言で const を優先的に使用します。
  • let (変数): 値が後から再代入される場合に使用します。

スコープ（有効範囲）の種類

  • グローバルスコープ: プログラム全体から参照可能。
  • 関数スコープ: function 内で有効。
  • ブロックスコープ: { ... }（if文やfor文など）の中で有効。const と let はブロックスコープに従います。
// ブロックスコープの例
{
  const x = 10;
  let y = 20;
}
// console.log(x); // ReferenceError: x is not defined
// console.log(y); // ReferenceError: y is not defined

1.2 基本的なデータ型と型変換

JavaScriptのデータ型は大きくプリミティブ型とオブジェクト型に分かれます。

分類 データ型 説明 / 例
プリミティブ型
(不変・値渡し)		 string 文字列 ("Hello", 'JS')
number 数値 (10, 3.14, Infinity, NaN)
boolean 真偽値 (true / false)
undefined 未定義（値が設定されていない状態）
null 空の値（明示的に「何もない」ことを意味する）
symbol / bigint 一意の値 / 巨大な整数
オブジェクト型 Object, Array, Function

型変換（Implicit & Explicit Type Conversion）

JavaScriptでは自動的に型が変換される「暗黙の型変換」と、関数を使って意図的に行う「明示的な型変換」があります。

// 暗黙の型変換
console.log("5" + 3);  // "53" (数値が文字列に結合される)
console.log("5" - 3);  // 2    (文字列が自動的に数値に変換される)

// 明示的な型変換
const strNum = "123";
const num = Number(strNum); // 数値型 123
const str = String(100);    // 文字列型 "100"
const bool = Boolean(1);    // true (0は false, 1以上は true)

1.3 制御構文

条件分岐 (if / switch)

// if / else if / else
const score = 85;
if (score >= 90) {
  console.log("A判定");
} else if (score >= 70) {
  console.log("B判定");
} else {
  console.log("C判定");
}

// switch
const role = "admin";
switch (role) {
  case "admin":
    console.log("管理者権限");
    break;
  case "user":
    console.log("一般ユーザー");
    break;
  default:
    console.log("ゲスト");
}

ループ (for / while)

// for ループ
for (let i = 0; i < 3; i++) {
  console.log(`カウント: ${i}`);
}

// while ループ
let count = 0;
while (count < 3) {
  console.log(`while: ${count}`);
  count++;
}

2. オブジェクトの徹底理解

2.1 プロパティの取得・追加・削除・階層アクセス

オブジェクトは「キーと値（キー・バリュー）」のペアでデータを保持します。

const user = {
  name: "Alice",
  age: 25,
  address: {
    city: "Tokyo",
    zip: "100-0001"
  }
};

// 1. プロパティの取得 (ドット記法 & ブラケット記法)
console.log(user.name);         // "Alice"
console.log(user["age"]);       // 25

// 2. 追加・更新
user.job = "Developer";         // 追加
user.age = 26;                  // 更新

// 3. 削除
delete user.job;

// 4. 階層アクセス & オプショナルチェイニング (?.)
// 存在しないプロパティでもエラーを出さず undefined を返す
console.log(user.address?.city);  // "Tokyo"
console.log(user.company?.name);  // undefined

2.2 メソッドの定義と使い方

オブジェクトのプロパティに関数を割り当てたものを「メソッド」と呼びます。

const calculator = {
  factor: 2,
  // ES6の省略記法
  multiply(number) {
    // this はこのオブジェクト自身を指す
    return number * this.factor;
  }
};

console.log(calculator.multiply(5)); // 10

2.3 オブジェクトの分割代入・スプレッド構文

分割代入 (Destructuring Assignment)

const person = { name: "Bob", age: 30, country: "Japan" };

// オブジェクトから特定のプロパティを抽出
const { name, age } = person;
console.log(name, age); // "Bob" 30

スプレッド構文 (Spread Syntax `...`)

const item = { id: 1, title: "Book" };
const details = { price: 1500, stock: 10 };

// オブジェクトのマージ（結合）
const product = { ...item, ...details, category: "Goods" };
console.log(product); // { id: 1, title: "Book", price: 1500, stock: 10, category: "Goods" }

2.4 値渡しと参照渡しの違い（シャローコピー / ディープコピー）

重要原則:
  • プリミティブ型: 「値渡し」→ コピー時に値そのものが新しく作成される（お互いに影響しない）。
  • オブジェクト型: 「参照渡し」→ コピー時にメモリ上の参照先アドレスが共有される（一方の変更が他方に波及する）。
// 参照渡しの罠
const objA = { count: 1 };
const objB = objA; // 参照がコピーされる
objB.count = 99;
console.log(objA.count); // 99 (objAの内容も変わってしまう)

// シャローコピー (浅いコピー: 1階層目のみ独立複製)
const shallowCopy = { ...objA };

// ディープコピー (深いコピー: ネストしたすべての階層を完全独立複製)
const deepCopy = structuredClone(objA); // モダンJS標準機能

3. 関数の深掘り

3.1 関数宣言、関数式、アロー関数の使い分け

// 1. 関数宣言 (Hoisting: 宣言前に呼び出し可能)
function sum1(a, b) {
  return a + b;
}

// 2. 関数式 (変数に代入。定義前の実行は不可)
const sum2 = function(a, b) {
  return a + b;
};

// 3. アロー関数 (ES6〜 簡潔な記法。自身の this を持たない)
const sum3 = (a, b) => a + b;

3.2 引数（デフォルト引数、残余引数 ...args）

// デフォルト引数 (引数が渡されない・undefinedの時の初期値)
function greet(name = "ゲスト") {
  console.log(`こんにちは、${name}さん`);
}
greet(); // "こんにちは、ゲストさん"

// 残余引数 (Rest Parameters) : 複数の引数を配列として受け取る
function calculateTotal(...prices) {
  return prices.reduce((acc, curr) => acc + curr, 0);
}
console.log(calculateTotal(100, 200, 300)); // 600

3.3 関数の返り値（return）の設計と実際の利用パターン

関数の役割は「入力を受け取り、処理を行い、return で呼び出し元に結果を渡す」ことです。単一責任の原則に従い、処理結果を関数外へ渡す設計を行います。

// 関数の連携パターン
function validateAge(age) {
  return age >= 18;
}

function getAccessMessage(user) {
  // 別の関数を内部で呼び出して連携
  const isAdult = validateAge(user.age);
  if (isAdult) {
    return `${user.name}さんはアクセス可能です。`;
  }
  return `${user.name}さんは未成年です。`;
}

const userAccount = { name: "Taro", age: 20 };
const result = getAccessMessage(userAccount);
console.log(result); // "Taroさんはアクセス可能です。"

4. ブラウザ機能 & イベント全網羅（DOM Events）

4.1 DOM取得・変更

// 1. DOMの取得
const titleEl = document.querySelector("#title"); // 単一要素
const items = document.querySelectorAll(".item");   // 該当する全要素 (NodeList)

// 2. テキスト・HTML内容の変更
titleEl.textContent = "新しいタイトル"; // セキュアなテキスト挿入

// 3. クラス（スタイル）操作
titleEl.classList.add("active");      // クラス追加
titleEl.classList.remove("hidden");   // クラス削除
titleEl.classList.toggle("highlight");// なければ追加、あれば削除
console.log(titleEl.classList.contains("active")); // true

4.2 イベント分類と実践

addEventListener('event', callback) を使用して各種イベントを監視します。

カテゴリー 主なイベント名 説明
マウス・ポインター系 click, pointerdown, pointermove, pointerup, contextmenu クリック、タッチ/マウスの押し込み、移動、離した時、右クリックメニュー開画時。
キーボード系 keydown, keyup キーを押した瞬間、離した瞬間。
フォーム・入力系 input, change, submit, focus, blur 入力時のリアルタイム変更、確定時、送信時、フォーカス取得/外れた時。
ウィンドウ・ビューポート系 resize, scroll, DOMContentLoaded, load 画面リサイズ、スクロール、DOM構築完了、画像を含む全リソース読み込み完了。
タッチ・ドラッグ系 touchstart, touchmove, dragstart, drop スマホ等のタッチ開始/移動、ドラッグ開始/ドロップ処理。

キーボード判定の実践コード (e.key vs e.code)

document.addEventListener("keydown", (e) => {
  // e.key  : 入力された文字・意味 (例: "a", "Enter", "A")
  // e.code : 物理的なキー位置 (例: "KeyA", "Enter")
  if (e.code === "Enter") {
    console.log("Enterキーが押されました");
  }
});

4.3 イベントオブジェクト（e.preventDefault, e.stopPropagation, イベント委譲）

1. `e.preventDefault()` : デフォルト動作のキャンセル

フォーム送信時のページリロードや、リンク（<a>）の遷移などの標準動作を停止します。

const form = document.querySelector("#myForm");
form.addEventListener("submit", (e) => {
  e.preventDefault(); // 画面リロードを停止
  console.log("JS側で送信処理を実行します");
});

2. `e.stopPropagation()` : イベント伝播（バブリング）の停止

子要素で発生したイベントが親要素に連鎖的に伝わる（バブリングする）のを防ぎます。

const button = document.querySelector("#childBtn");
button.addEventListener("click", (e) => {
  e.stopPropagation(); // 親要素へのイベント伝播を停止
  console.log("ボタンのみ処理を実行");
});

3. イベント委譲（Event Delegation）

親要素に1つだけリスナーを設定し、子要素（または動的に追加された要素）のイベントをまとめて効率的に管理する設計パターンです。

// HTML構造例: <ul id="list"><li>Item 1</li><li>Item 2</li></ul>

const list = document.querySelector("#list");

// 親要素 ul にイベントリスナーを設定
list.addEventListener("click", (e) => {
  // クリックされたターゲットが li 要素か判定
  const targetItem = e.target.closest("li");
  
  if (targetItem && list.contains(targetItem)) {
    console.log(`クリックされた要素: ${targetItem.textContent}`);
  }
});
