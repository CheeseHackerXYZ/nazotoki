Web開発マスターガイド：HTML・CSS・JSの極意

タグの基礎から、デザイン配置、JavaScriptでの動的アニメーション・画面遷移までを一気に学ぶ完全版

第1章：HTMLの基本構造と主要タグ

HTMLはWebページの「骨組み」です。基本ルールは「<タグ名> と </タグ名> で文字や要素を挟む」だけです。

1. 全体の基本構文

どんなWebページも、必ずこの基本形から始まります。

<!DOCTYPE html> <!-- これはHTML5で書かれていますという宣言 -->
<html lang="ja">
  <head>
    <!-- 画面には表示されない「裏側の設定」を書く場所 -->
  </head>
  <body>
    <!-- 実際に画面に表示される「中身」を書く場所 -->
  </body>
</html>

2. <head> 内に書く設定タグ

  • <meta charset="UTF-8">：文字化けを防ぐおまじない（必須）。
  • <meta name="viewport" content="width=device-width, initial-scale=1.0">：スマホやiPadで見たときに、画面サイズをピタッと合わせる設定。
  • <meta name="robots" content="noindex">：Google検索などの検索結果に「表示させないでね」という指示（テスト公開時などに使う）。
  • <style>：この中にCSS（デザイン）を書き込みます。

3. <body> 内の主要な表示タグ

タグ名 役割 具体的な使い方
h1 〜 h3 見出し (Heading) <h1>一番デカいタイトル</h1>
p 段落 (Paragraph) <p>普通の文章を書くときはコレで挟みます。</p>
div ブロックの箱 複数の要素をグループにまとめるための透明な箱。
span インラインの箱 文章の「一部だけ」色を変えたい時などに使う箱。
button ボタン <button>押してね</button>
input 入力欄 文字を打ち込む枠。※ </input> で閉じない単独タグ。
img 画像表示 画像を出す。※ これも閉じない単独タグ。
a リンク（移動） <a href="URL">ここを押すと飛ぶよ</a>
💡 知っておくとカッコいい応用タグ（存在だけ紹介！）
  • <iframe>：自分のページの中に、YouTubeや他のWebサイトの小窓を「埋め込む」ことができます。
  • <canvas>：絵を描くための画用紙。JSを組み合わせると、図形を描いたりゲーム画面を作ったりできます。

4. 【重要】<script> タグを書く場所と実行順序

JavaScriptを読み込む <script> は、<body> の一番下（閉じる直前）に書くのが基本です。

理由は、ブラウザがHTMLを「上から下へ順番に」読み込むからです。もし <head> の中にJSを書くと、「まだHTMLの画面が作られていないのにJSが動こうとしてエラーになる」ことがあります。お尻に書けば、画面が完成してからJSが動くので安全です。

第2章：属性（Attribute）とパス

タグの中に埋め込んで、機能や名前などの「追加情報」を持たせるものを属性と呼びます。

1. よく使う属性一覧

  • type： input に使います。（例：type="text" なら文字、type="password" なら伏せ字、type="number" なら数字専用）
  • value： 入力欄の「初期値」や、ボタンの文字。（例：<input value="最初の文字">）
  • src： 画像やファイルの「場所」を指定。（例：<img src="pic.jpg">）
  • href： リンク先のURL。（例：<a href="https://...">）
  • style： HTMLの中に直接CSSを書く。（例：<p style="color: red;">）
  • onclick： クリックされた時にJSを動かす。（例：<button onclick="関数名()">）

2. 【超重要】id と class の決定的な違い

CSSでデザインを当てたり、JSで要素を操作するためには、タグに「名前」をつける必要があります。それが id と class です。

🔴 id (アイディー) = ページに1人だけの「背番号」

同じページ内に同じ名前は1回しか使えません。 JSで「あの要素だけを確実に動かしたい！」という時に使います。（例：id="main-title"）

🔵 class (クラス) = みんなで共有する「学年・組」

同じページに何回でも使い回せます。 CSSで「このグループは全部赤色にして」とまとめてデザインするときに使います。（例：class="red-button"）

📂 【コラム】絶対パス vs 相対パス（リンクや画像の場所の書き方）

絶対パス： https://example.com/img/a.jpg のように、地球上のどこからでも辿り着ける完全なURL。外部サイトに繋ぐ時に使います。

相対パス： ./img/a.jpg や ../index.html のように、「今のファイルから見て、どこにあるか」を指定する方法。自分のプロジェクト内（フォルダ内）を行き来する時は、必ず相対パスを使います（サーバーにアップした時にリンク切れしないため）。

第3章：CSSでデザインとレイアウトを操る

CSSは「どの要素を」「どうする」というルールで書きます。

/* セレクタ { プロパティ: 値; } */
p { color: red; }            /* タグ名を指定 */
.red-button { color: red; }  /* クラス名を指定（先頭にドット . ） */
#main-title { color: blue; } /* id名を指定（先頭にハッシュ # ） */

1. 主なプロパティ

  • color：文字の色
  • background-color：背景の色
  • font-family：フォントの種類（ゴシック体、明朝体など）
  • font-size：文字の大きさ（pxやremで指定）
  • width / height：横幅 / 高さ
  • z-index：重なりの順序（数字が大きいほど手前・上にくる）

2. 枠線の「外側」か「内側」か（margin と padding）

初心者が一番迷うポイントです。要素には「目に見えない枠（Border）」があります。

[ ↑ margin (外側のすき間・隣との距離) ]
----------------------------------------- (枠線 Border)
[ ↓ padding (内側のゆとり・文字までの距離) ]
コンテンツ (文字など)

ボタンを例にすると、padding を増やすと「ボタン自体がデカく（ふっくら）」なり、margin を増やすと「隣のボタンとの距離が離れる」ことになります。

3. レイアウトの最強呪文「display」

要素の並び方を決定する超重要プロパティです。

display: block;ブロック（箱）： 横幅いっぱいに広がり、前後に改行が入る（h1やdivの初期値）。
display: inline;インライン（文字の一部）： 改行されず横に並ぶ。幅(width)や高さは指定できない（spanやaの初期値）。
display: flex;フレックス： 中の要素を自由自在に横並び・中央揃えにできる現代の最強レイアウト。
display: none;非表示： 画面から完全に消し去る。JSと組み合わせて「クリックで表示/非表示」によく使う。

第4章：JavaScriptで動きとロジックを作る

1. 基本中の基本

  • 変数（let）と定数（const）： 値を入れておく箱です。昔は var がありましたが今は使いません。途中で中身が変わるなら let、絶対変わらないなら const を使います。
  • 文字列： 文字は必ず "こんにちは" か 'こんにちは' のようにクォーテーションで囲みます。
  • 配列： 複数のデータをひとまとめにします。let arr = [1, 2, 3]; のように [ ] を使います。

2. JSからHTMLを操る（DOM操作）

JSで画面を書き換えるには、まず document.getElementById() で要素（idの背番号）を捕まえます。

// ① HTMLにある  の中身を書き換える
let inputElement = document.getElementById("myInput");
inputElement.value = "書き換えました！";

// ② HTMLにある 
 のCSS（色と表示）を書き換える
let boxElement = document.getElementById("myBox");
boxElement.style.backgroundColor = "blue"; // JSではハイフンを使わず大文字にする（camelCase）
boxElement.style.display = "none";         // 画面から消す

3. 関数（function）とイベント

「〜する処理」をひとまとめにしたものが関数です。引数（ひきすう）を渡すと、少しずつ動きを変えて使い回せます。

// 引数（message）を受け取って表示する関数
function showMessage(message) {
    alert(message);
}

これをHTMLの onclick 属性と組み合わせると、ボタンが押された時にJSが走ります。
例：<button onclick="showMessage('こんにちは！')">押す</button>

4. 【超便利】丸暗記すべき4つの魔法のコマンド

console.log("ログ");
画面には出ず、開発者ツールの「Console」に表示されます。変数の値がちゃんと取れているか、裏側で確認（デバッグ）する時の最強ツールです。

alert("文章");
画面にポップアップ通知を出します。（iPadなどで開発者ツールが見づらい環境では、これがデバッグ代わりになって超便利です！）

window.location.href = "https://...";
今の画面を、指定したURLに移動（ページ遷移）させます。

window.open("https://...");
新しいタブ（別ウィンドウ）を開いて、指定したURLを表示させます。

第5章：総合まとめ！魔法のステータスカード

ここまで学んだ HTML + CSS + JS を全部組み合わせた1枚のサンプルコードです。

<!DOCTYPE html>
<html lang="ja">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <style>
    /* --- CSSの世界 --- */
    body {
      background-color: #f1f5f9;
      font-family: sans-serif;
    }
    
    /* フレックスボックスで画面のド真ん中に配置 */
    .container {
      display: flex;
      flex-direction: column; 
      align-items: center;
      margin-top: 50px;
    }
    
    /* カードのデザイン */
    #statusBox {
      background-color: white;
      padding: 20px;       /* 内側のゆとり */
      margin-bottom: 20px; /* 外側（下）のすき間 */
      width: 300px;
      border: 2px solid #333;
      text-align: center;
    }
  </style>
</head>
<body>
  <!-- --- HTMLの世界 --- -->
  <div class="container">
    <h2>ステータス変更パネル</h2>

    <!-- idはJavaScriptで操作するための背番号 -->
    <div id="statusBox">
      <h3 id="nameText">名無し</h3>
      <p>レベル: <span id="levelText">1</span></p>
    </div>

    <!-- 文字入力欄（初期値は空） -->
    <input type="text" id="nameInput" value="" placeholder="名前を入力">
    
    <!-- onclickでJSの関数を呼び出す -->
    <button onclick="updateStatus()" style="margin-top: 10px;">更新する！</button>
    
    <!-- aタグで別ページへのリンク（相対パスの例） -->
    <a href="./next-page.html" style="margin-top: 20px;">次のページへ移動</a>
  </div>

  <!-- --- JavaScriptの世界 (HTMLの下に書く) --- -->
  <script>
    // 「更新する！」ボタンを押したときに呼ばれる関数
    function updateStatus() {
      // 1. input要素を取得して、入力された文字(value)を取り出す
      const inputElement = document.getElementById("nameInput");
      const newName = inputElement.value; // letではなくconstで安全に値を取得
      
      // もし名前が空っぽなら、アラートを出して終了（ガード節）
      if (newName === "") {
        alert("名前を入力してください！");
        return; 
      }
      
      // 2. 名前の表示(h3)を書き換える
      const nameTextElement = document.getElementById("nameText");
      nameTextElement.innerHTML = newName;
      
      // 3. statusBoxの背景色をCSS(style)で青色に変える
      const boxElement = document.getElementById("statusBox");
      boxElement.style.backgroundColor = "#e0f2fe";
      
      // 4. 裏側で確認用のログを出す
      console.log("名前が " + newName + " に更新されました！");
    }
  </script>
</body>
</html>
