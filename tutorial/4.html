CSS完全攻略教科書

基礎構文・レスポンシブ単位・現代レイアウト（Flex/Grid）・CSS変数・アニメーションまで完全網羅

第1章：CSSの基本構造とセレクタ

CSS（Cascading Style Sheets）は、HTMLの要素に対して「どの部分を（セレクタ）」「何を（プロパティ）」「どう変えるか（値）」を指定する言語です。

1. 基本構文

/* セレクタ { プロパティ: 値; } */
p {
  color: #2563eb; /* 文字色を青にする */
  font-size: 16px; /* 文字サイズを16pxにする */
}

2. セレクタの種類と優先順位

セレクタ名 書き方 対象 特徴・使い道
全称セレクタ * すべての要素 後述のリセットCSS（余白のゼロ初期化など）で使用。
要素名セレクタ p, div 指定したHTMLタグ全体 全体のデフォルトデザインを設定するときに使用。
クラスセレクタ .btn class="btn" をもつ要素 何回でも使い回せる。デザインの基本はコレ！
idセレクタ #header id="header" をもつ要素 ページに1つだけ。優先度が高いため乱用注意。
💡 最強の初期化プロパティ * （全称セレクタ）

現代のWeb制作では、1行目に以下のおまじないを書くのが標準となっています。

* {
  box-sizing: border-box; /* 枠線と余白を幅に含める */
  margin: 0;              /* ブラウザ独自の無駄な外余白を消す */
  padding: 0;             /* ブラウザ独自の無駄な内余白を消す */
}

第2章：サイズと単位（Unit）の完全理解

CSSでサイズや距離を指定する単位には、絶対値と相対値が存在します。これらを理解することがレスポンシブWebデザイン（画面幅に合わせた最適化）の鍵です。

1. CSSで使う単位一覧

分類 単位 意味・基準 主な使い道
絶対単位 px ピクセル（固定値） 枠線の太さや、小さな固定アイコンなど。
相対単位 % 親要素のサイズに対する割合 コンテナの幅指定やレスポンシブな画像サイズ。
rem ルート（<html>）の文字サイズに対する倍率 文字サイズや余白の基本指定（1rem = 16px程度）。
em 親要素（または自身）の文字サイズに対する倍率 文字の大きさに連動させたい余白やインデント。
vw / vh 画面（ビューポート）の幅 / 高さの 1% 画面いっぱいのヒーローイメージ（100vw / 100vh）。
svh / dvh スマホのツールバー考慮版の高さ単位 モバイル端末でスクロール時に高さがズレない設定。
fr Gridレイアウト専用の「フリースペースの分配比率」 grid-template-columns: 1fr 2fr; など。
特殊単位 s / ms 時間（秒 / ミリ秒） アニメーションの所要時間（0.3s など）。
deg 角度（Degree：度） 要素の回転（rotate(45deg) など）。

2. ボックスサイズ関連プロパティ

  • width / height：横幅と高さ。
  • min-width / max-width：最小幅・最大幅。（例：max-width: 1200px; と width: 100%; を組み合わせると、PCでは1200px上限、スマホでは画面幅いっぱいに収まるレスポンシブな箱ができる）
  • min-height / max-height：最小高さ・最大高さ。
  • box-sizing：content-box（標準：サイズにBorderやPaddingが含まれない）か border-box（推奨：指定したwidthの中にBorderもPaddingも全部納める）かを決定。
  • aspect-ratio：アスペクト比（縦横比）の固定。例：aspect-ratio: 16 / 9; や aspect-ratio: 1 / 1; (正方形)。

第3章：テキストとタイポグラフィ

文字を美しく読みやすく整えるためのスタイルプロパティです。

1. フォントと文字のスタイル

  • color：文字の色（HEX: #ff0000、RGB: rgb(255,0,0)、カラー名: red などで指定）。
  • font-family：フォントの種類（例：font-family: 'Helvetica Neue', sans-serif;）。後ろにフォールバックフォントを用意する。
  • font-size：文字の大きさ（例：1.2rem, 18px）。
  • font-weight：文字の太さ（normal, bold、または 100〜900 の数値）。
  • font-style：斜体などの指定（normal, italic）。
  • font：上記を一括で書くショートハンド。

2. 文章の組み・配置プロパティ

  • line-height：行の高さ（行間）。単位なしの数値（1.6 や 1.75）で指定するのがベスト実践！
  • letter-spacing：文字と文字の間隔（例：0.05em）。
  • text-align：文字の揃え位置（left, center, right, justify）。
  • text-decoration：文字の装飾（none でリンクの線を消す、underline で下線、line-through で打ち消し線）。
  • text-transform：英字の大文字/小文字変換（uppercase で全大文字、lowercase、capitalize）。
  • text-shadow：文字の影。（例：text-shadow: 2px 2px 4px rgba(0,0,0,0.3);）
  • white-space：改行や空白の扱い（nowrap で自動改行を禁止、pre-wrap でコード等そのまま表示）。
  • list-style：箇条書き（<ul>, <li>）の黒丸などを消す（list-style: none;）。

第4章：ボックスモデルと余白（margin / padding）

すべてのHTML要素は「四角い箱（ボックス）」として作られます。枠線の内外にある余白を正しくコントロールすることがデザインの基礎です。

[ margin (枠線の外側のすき間) ]
----------------------------------------- (border 枠線)
| [ padding (枠線の内側のゆとり) ] |
| コンテンツ (文字や画像などの本体) |
-----------------------------------------

1. margin（外側余白）と padding（内側余白）

プロパティ 対象 個別指定のプロパティ
margin 枠線の外側の余白（隣の要素との距離） margin-top, margin-right, margin-bottom, margin-left
padding 枠線の内側の余白（コンテンツと枠線の間のゆとり） padding-top, padding-right, padding-bottom, padding-left

2. 一括指定（ショートハンド）の書き方パターン

/* 1つ指定：上下左右すべて */
margin: 20px;

/* 2つ指定：[上下] [左右] */
margin: 10px 20px; /* 上下10px, 左右20px */

/* 3つ指定：[上] [左右] [下] */
margin: 10px 20px 30px;

/* 4つ指定：[上] [右] [下] [左] (時計回り) */
margin: 10px 20px 30px 40px;

/* 中央揃えの超定番テクニック */
margin: 0 auto; /* 上下0、左右自動（中央に寄る） */

第5章：背景・枠線・影の質感装飾

1. 背景（Background）

  • background-color：背景色（例：#f1f5f9）。
  • background-image：背景画像（例：url('bg.jpg')）。
  • background-size：背景画像のサイズ調整。
    • cover：アスペクト比を維持し、領域全体をスキマなく覆う（一番よく使う！）。
    • contain：画像全体が収まるように自動縮小。
  • background-position：画像の配置位置（例：center, top right）。
  • background-repeat：画像の繰り返し（no-repeat で1回だけ表示）。
  • background：上記を一括指定するショートハンド。

2. 枠線（Border）と輪郭（Outline）

  • border：枠線の一括指定（例：border: 2px solid #2563eb;）。
  • border-width / border-style / border-color：個別に太さ・種類（solid, dashed, dotted）・色を指定。
  • border-radius：角を丸くする。（例：border-radius: 8px;、50% で完全な正円）
  • outline：Borderのさらに外側に引かれる輪郭線。レイアウトの幅に影響を与えないため、入力フォームのフォーカス強調などで使われます。

3. ドロップシャドウ（box-shadow）

要素に立体的な影を落とします。

/* box-shadow: [横ずらし] [縦ずらし] [ぼかし具合] [広がり] [色]; */
box-shadow: 0px 4px 10px 0px rgba(0, 0, 0, 0.15);

第6章：レイアウトと位置指定（Position・Display）

1. display（要素の表示形式）

  • block：横幅いっぱいに広がり、前後に改行が入る箱（div, p, h1 など）。
  • inline：文章の一部として横に並ぶ（span, a など）。幅や高さの指定は効かない。
  • inline-block：横に並びつつ、width や height、margin も指定できる万能な箱。
  • none：画面から完全に消失させる（DOM上には存在するが画面に描画されない）。

2. position（配置の基準）と位置指定

position プロパティを指定することで、top / right / bottom / left を使って自由な位置に要素を配置できます。

値 特徴・基準 主な使い道
static デフォルト。通常の要素の並び順に従う（top/leftは効かない）。 位置指定の解除。
relative 「本来自分があるはずだった場所」を基準にして移動。 子要素に absolute を使う際の親の基準点として設置。
absolute position: relative; がついた一番近い親要素を基準に絶対配置。 カード画像の右上に「NEW」バッジを重ねて貼るなど。
fixed 「ブラウザの画面全体（ビューポート）」を基準に固定。 画面下部に常駐するナビボタンや固定ヘッダー。
sticky 通常通りスクロールし、指定位置に来たら固定される。 見出しやサイドバーの追従表示。

3. 重なり順とあふれた中身の処理

  • z-index：要素の重なり順を数値で指定（例：z-index: 100;）。数値が大きいほど手前に表示されます。※ position（static以外）がついている要素で動作します。
  • overflow / overflow-x / overflow-y：親の箱から中身がはみ出た時の挙動。
    • visible：はみ出たまま表示（デフォルト）。
    • hidden：はみ出た部分を切り落として隠す。
    • scroll：常にスクロールバーを表示する。
    • auto：はみ出た時だけ自動でスクロールバーを出す。
  • visibility：hidden にすると要素が見えなくなるが、display: none と違って「領域のスペースは残ったまま」になる。
  • opacity：透明度（0.0完全透明 〜 1.0完全不透明）。

第7章：Flexbox ＆ CSS Grid（現代レイアウト）

1. Flexbox（1次元レイアウト：横並び・縦並び）

親要素に display: flex; を指定するだけで、子要素を自在に並べることができます。

  • flex-direction：並べる方向。row（横並び：デフォルト）、column（縦並び）。
  • flex-wrap：折り返し設定。nowrap（折り返さない）、wrap（端まで行ったら折り返す）。
  • justify-content：メイン軸（並ぶ方向）の揃え。
    • flex-start（左揃え）、center（中央揃え）、flex-end（右揃え）
    • space-between（両端に寄せて均行配置）、space-around（均等な余白をつける）
  • align-items：クロス軸（直交する方向）の揃え。center（上下中央）、stretch（高さを揃える）。
  • gap：要素同士のすき間を一発で指定（例：gap: 16px;）。margin 不要になる神プロパティ！
  • flex：子要素側につけ、比率で伸縮させる（例：flex: 1;）。
  • align-self：特定の1つの子要素だけ、個別に上下揃えを上書きする。

2. CSS Grid（2次元レイアウト：行と列の格子状配置）

縦と横の「マス目」を作って要素をはめ込む強力なレイアウト機構です。

.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr); /* 3列均等に並べる */
  gap: 20px;                             /* マス目間の余白 */
  place-items: center;                   /* 上下左右の中央揃えが一発で完了！ */
}

.grid-item-wide {
  grid-column: 1 / 3; /* 1列目から3列目の手前まで（2マス分）を連結 */
  grid-row: 1 / 2;    /* 1行目 */
}

第8章：CSSの便利機能（関数・変数）

1. CSS変数（カスタムプロパティ）

サイト内で使う色やサイズを定数として保存し、使い回すことができます。テーマカラーの一括変更などに超強力です。

/* 1. :root (全体で使える場所) に変数を定義 */
:root {
  --main-color: #2563eb;
  --bgcolor-red: #ef4444;
  --card-padding: 20px;
}

/* 2. var() 関数で呼び出して使用 */
.button {
  background-color: var(--main-color);
  padding: var(--card-padding);
}

.alert-box {
  background-color: var(--bgcolor-red);
}

2. CSSの計算関数 calc() とレスポンシブ関数

  • calc()：異なる単位同士で計算ができる関数。 
    /* 画面横幅100%から、サイドバーの250px分を引き算したサイズにする */
width: calc(100% - 250px);
  • clamp(最小値, 推奨値, 最大値)：画面幅に合わせて自動で伸縮しつつ、最小・最大サイズでピタッと止まるレスポンシブ関数。 
    /* 文字サイズ：最小16px、通常は画面幅の5vw、最大32px */
font-size: clamp(16px, 5vw, 32px);
  • min() / max()：渡された値の中から「最も小さい値 / 最も大きい値」を選択する。

第9章：アニメーション・視覚効果・操作性

1. 画像のフィットと特殊フィルター

  • object-fit：<img> タグの画像を、親枠に合わせてどうトリミングするか（cover で枠全体を埋める、contain で全体を見せる）。
  • object-position：トリミング時の中心位置（例：center top）。
  • filter：画像や要素に視覚効果を与える。（例：filter: blur(5px); でぼかし、grayscale(100%) で白黒）
  • clip-path：要素をポリゴンや円など好きな形に切り抜く（例：clip-path: circle(50%);）。

2. トランジションとトランスフォーム（変形・滑らかな変化）

  • transition：状態が変わる時の滑らかな変化アニメーション。 
    /* プロパティ 時間 タイミング関数 */
transition: all 0.3s ease;
  • transition-duration：変化にかかる時間（例：0.5s）。
  • transition-timing-function：変化の加速・減速パターン（ease, linear, ease-in-out）。
  • transform：要素の移動・回転・拡大縮小。 
    transform: rotate(45deg);       /* 45度回転 */
transform: scale(1.2);          /* 1.2倍に拡大 */
transform: translate(10px, 20px);/* 横10px, 縦20px移動 */
  • transform-origin：変形の基準点（例：top left）。

3. 本格キーフレームアニメーション

@keyframes でアニメーションのコマ割りを定義し、animation で呼び出します。

@keyframes pulse {
  0%   { transform: scale(1); }
  50%  { transform: scale(1.1); }
  100% { transform: scale(1); }
}

.badge {
  /* アニメーション名 時間 繰り返し */
  animation: pulse 2s infinite;
}

4. ユーザー操作（UI）と擬似要素

  • cursor：マウスカーソルの形状（pointer で手持ちマーク、not-allowed で禁止マーク）。
  • pointer-events：クリック等の操作を透過させるか（none でクリックに反応しなくなる）。
  • user-select：テキスト選択（ドラッグして青く反転させる操作）を許可するか（none で選択不可）。
  • touch-action：スマホ/iPadでのピンチズームやスワイプ操作の制限。
  • content：擬似要素（::before, ::after）でHTMLを使わずに文字や装飾パーツを注入するプロパティ。（例：content: "★";）

第10章：アットルール（@）とレスポンシブデザイン

ブラウザに対して特殊な命令を与える構文をアットルール（At-Rules）と呼びます。

主なアットルール一覧

構文 役割 具体例
@media 画面サイズ等の条件によってCSSを切り替える（メディアクエリ） スマホ対応（レスポンシブデザイン）に必須。
@keyframes アニメーションのコマ割り（途中経過）を定義する 0% 〜 100% の間の変化を指定。
@font-face 外部のWebフォントファイルを読み込んで定義する Google Fonts などの自前読み込み。
@import 他のCSSファイルを外部からインポートして読み込む ファイル分割管理時に使用。

【実践】レスポンシブWebデザイン（@media）の書く順序

スマホファースト（画面が小さい順）で記述するのが現代の標準です。

/* 1. デフォルトスタイル（スマホ用） */
.card {
  width: 100%; /* スマホでは縦並び・幅100% */
}

/* 2. タブレット以上（画面幅 768px 以上）で適用 */
@media (min-width: 768px) {
  .card {
    width: 50%; /* 横並び2列にする */
  }
}

/* 3. PC以上（画面幅 1024px 以上）で適用 */
@media (min-width: 1024px) {
  .card {
    width: 33.333%; /* 横並び3列にする */
  }
}
